# 공유 계정 로그인 게이트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공개된 Supabase publishable key만으로 가족 금융데이터를 읽고 쓸 수 있는 상태를 끝낸다 — Supabase Auth 공유 계정 1개로 게이트를 세우고, 가계부 6개 테이블의 RLS를 `to authenticated`로 좁힌다.

**Architecture:** Worker 프록시나 자체 인증 코드를 만들지 않는다. `supabase-js`가 세션·토큰 갱신을 처리하고, Supabase가 로그인 레이트리밋을 처리한다. 앱은 시작 흐름에 세션 확인 한 단계만 추가되며 `sb.from(...)` 호출부는 바뀌지 않는다. 정적 자산 노출(`/CLAUDE.md`·`/.git/**`)은 `.assetsignore`로 별도 차단한다.

**Tech Stack:** `@supabase/supabase-js@2` (CDN, 이미 로드 중) · Cloudflare Workers Static Assets · Node 24 (검증 스크립트) · 헤드리스 Chrome (렌더 확인)

  });
  try { DEVICE_USER = localStorage.getItem(DEVICE_USER_KEY) || null; } catch(e){ DEVICE_USER = null; }
  buildNav();
  // 세션 만료·비밀번호 변경 시 로그인 화면으로 되돌린다.
  // 이게 없으면 빨간 '데이터 연결 오류' 카드가 떠서 원인을 오도한다(RLS 문제로 오인)
  sb.auth.onAuthStateChange(ev => { if(ev==="SIGNED_OUT") showAuth(); });

async function startApp(){

// 빈 배열이 200으로 와서 '차단됐다'고 오독하기 쉽다 → 그 경우를 명시적으로 실패 처리한다
const https = require("https");
const HOST = "hqyvkyflakhuvethrstw.supabase.co";
const KEY  = "sb_publishable_phZGH7odPTBoB4z8FQF_4A_mO2ltQ6J";
const BUDGET = ["members","transactions","category_limits","master_data","tax_map","app_settings"];
const FOREST = ["forests"];   // 휴양림 무영향 확인용

function req(method, path, body){
  return new Promise((res, rej) => {
    const r = https.request({host:HOST, path, method,
      headers:{apikey:KEY, Authorization:"Bearer "+KEY, "Content-Type":"application/json"}}, x => {
      const bufs=[]; x.on("data",d=>bufs.push(d));
      x.on("end",()=>res({status:x.statusCode, body:Buffer.concat(bufs).toString("utf8")}));
    });
    r.on("error", rej);
    if(body) r.write(JSON.stringify(body));
    r.end();
  });
}

(async () => {
  let bad = 0;
  const say = (ok,msg) => { if(!ok) bad++; console.log(`${ok?"ok  ":"FAIL"} ${msg}`); };
